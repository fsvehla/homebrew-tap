# fsvehla/tap

Homebrew casks.

```
brew install fsvehla/tap/ambience
```

| Cask | App |
|---|---|
| `ambience` | [Ambience](https://github.com/fsvehla/bgm-audio): player for long background music and ambience files. Updates itself with Sparkle. |

`Casks/ambience.rb` is updated by `packaging/release.sh` in the app's repo on each release.
